
# INTRODUCTION


# PART 1 — INTELLIGENCE KYA HAI?

Socho ek student hai. Wo exam se pehle kitaab padhta hai, notes banata hai, formulas yaad karta hai. Ye hai learning. Phir wo exam hall mein baithta hai aur sawal dekhta hai. Usay samajh aata hai ke ye question kis type ka hai. Ye hai pattern recognition. Phir wo decide karta hai ke pehle kaunsa question solve karna hai. Ye hai decision making. Agar question mushkil ho to wo tootta nahi, balki apne dimaag ko lagata hai. Ye hai problem solving. Agar exam pattern change ho jaye to wo adjust karta hai. Ye hai adaptation. In sab cheezon ka naam hi intelligence hai. Intelligence sirf maths ya science nahi hai. Intelligence mein memory, reasoning, planning, aur seekhne ki ability sab shamil hain. Insaan ka dimaag 86 billion neurons se bana hai. Jab hum kuch seekhte hain to neurons ke beech connections strong hote hain. Jab bhoolte hain to connections weak ho jate hain. AI bhi isi tarah kaam karta hai, lekin wo biological nahi, mathematical hai.

---

# PART 2 — ARTIFICIAL INTELLIGENCE KYA HAI?

Artificial Intelligence ka matlab hai machine ko aisa smart banana ke wo aise kaam kar sake jo normally insaan karta hai. Lekin yaad rakhein, AI insaan nahi hai. AI ko consciousness nahi hoti. AI ko emotions nahi hote. AI sirf data se patterns seekhta hai. Google Maps traffic predict karta hai, YouTube aapko videos suggest karta hai, face recognition aapka chehra pehchaan kar phone unlock karta hai, chatbot aapke sawalon ka jawab deta hai, bank fraud pakadta hai, doctor ko X-ray mein disease detect karne mein madad karta hai, aur self-driving car road par safely drive karti hai. Ye sab AI hai. AI ka purpose hai mushkil kaam asaan karna, repetitive kaam automate karna, bade data se patterns nikalna, aur predictions karna. Traditional programming mein insaan rules likhta hai aur computer follow karta hai. AI mein insaan data deta hai aur machine khud rules seekhta hai.

# PART 3 — AI KI HISTORY

AI ka safar 1950 se shuru hota hai. Alan Turing ne Turing Test propose kiya. 1956 mein Dartmouth Conference mein Artificial Intelligence term paida hua. 1960s aur 70s mein rule-based systems aaye. Phir 1980s mein expert systems aaye jaise MYCIN jo medical diagnosis karta tha. 1990s aur 2000s mein Machine Learning era aaya. Ab machine data se seekhne lagi. 2010s mein Deep Learning boom aaya. AlexNet ne ImageNet jeeta, AlphaGo ne world champion ko haraaya. 2017 mein Transformer paper aaya. 2020 mein GPT-3 aaya. 2022 mein ChatGPT launch hua. 2023 mein GPT-4, Claude, Gemini aaye. 2024 se AI Agents ka daur shuru ho gaya. Har era ne pichhle era ki limitation ko door kiya. Pehle rules manually likhne padte thay, phir data se seekhna shuru hua, phir deep networks aaye, phir generative AI aaya, aur ab agents autonomously kaam kar rahe hain.

# PART 4 — AI vs ML vs DL vs GENAI

AI sab se bada umbrella hai. Uske andar Machine Learning aata hai. ML ke andar Deep Learning aata hai. DL ke andar Generative AI aati hai. GenAI ke andar Large Language Models aate hain. Aur LLM ke andar AI Agents aate hain. AI ka matlab machine ko smart banana. ML ka matlab data se seekhna. DL ka matlab deep neural networks se seekhna. GenAI ka matlab naya content create karna. LLM ka matlab text samajhna aur generate karna. Agent ka matlab autonomously plan karke kaam karna. Jaise AI ek school hai, ML us school ki ek class hai, DL us class ka ek subject hai, GenAI us subject ka chapter hai, LLM us chapter ka topic hai, aur Agent us topic ka project hai.

# PART 5 — TRADITIONAL PROGRAMMING vs AI

Traditional programming mein aap rules likhte hain aur computer output deta hai. Jaise agar age 18 se zyada hai to adult. Machine Learning mein aap data aur examples dete hain, machine khud rules seekhta hai. Jaise aap 1000 students ka data dete hain jisme study hours, attendance, previous marks aur final marks hain. Machine seekh jati hai ke study hours aur attendance ka final marks se kya relation hai. Traditional programming deterministic hai, ML probabilistic hai. Traditional programming mein naye situation ke liye naya rule likhna padta hai, ML model generalize kar sakta hai. Traditional programming recipe book ki tarah hai, ML chef training ki tarah hai.

# PART 6 — MACHINE LEARNING

Machine Learning ki kuch types hoti hain. Supervised Learning mein aap input aur correct output dono dete hain. Jaise teacher student ko question aur answer dono dikhata hai. Isme Classification hoti hai jisme output category hoti hai jaise spam ya not spam. Aur Regression hoti hai jisme output number hota hai jaise house price. Unsupervised Learning mein aap sirf input dete hain, output nahi. Machine khud patterns dhoondta hai. Isme Clustering hoti hai jaise customer segmentation, Pattern Discovery hoti hai jaise market basket analysis, aur Dimensionality Reduction hoti hai jaise 1000 features ko 50 features mein convert karna. Semi-Supervised Learning mein thoda labeled data aur bohat sara unlabeled data hota hai. Self-Supervised Learning mein data khud labels generate karta hai, jaise LLM training. Reinforcement Learning mein Agent environment mein actions leta hai, rewards milte hain, aur wo seekhta hai. Isme Agent, Environment, State, Action, Reward, aur Policy hote hain. Jaise puppy ko train karna, acha kaam pe treat, bura kaam pe no.

# PART 7 — DATA

Data raw facts aur figures hain. Dataset data ka collection hai. Sample ek single data point hai. Feature input variable hai. Label output ya target hai. Training data wo hota hai jisse model seekhta hai. Validation data wo hota hai jisse model tune hota hai. Test data wo hota hai jisse final evaluation hoti hai. Jaise student dataset mein study hours, attendance, previous marks features hain aur final marks label hai. Model training data se seekhta hai, validation data par tune hota hai, aur test data par final exam deta hai.

# PART 8 — DATA QUALITY

Data quality bohat important hai. Missing data tab hota hai jab kuch values available nahi hoti. Duplicate data tab hota hai jab ek hi record do baar aa jata hai. Incorrect data tab hota hai jab galat values hoti hain jaise age -5. Noisy data mein random errors hote hain. Outliers wo values hoti hain jo baaki data se bohat door hoti hain. Jaise 45, 50, 52, 49, 51, 48, 99 mein 99 outlier hai. Lekin har outlier galat nahi hota. Fraud detection mein outlier fraud ka signal ho sakta hai. Medical data mein outlier bimari ka indication ho sakta hai. Sensor data mein outlier error ho sakta hai. Mean, Median, IQR, aur Z-score outlier detect karne ke tarike hain. Data Bias tab hota hai jab data kisi ek group ki taraf jhuka ho. Data Leakage tab hota hai jab training data mein test data ki information aa jaye.

---

# PART 9 — MACHINE LEARNING MODEL KAISE LEARN KARTA HAI?

Model learning ka process aise hai. Pehle input data aata hai. Model prediction karta hai. Phir error nikaalta hai. Error ko loss kehte hain. Phir optimization hoti hai. Phir weight update hota hai. Ye process repeat hota hai. Parameters wo numbers hain jo model seekhta hai. Weights batate hain ke kaunsa input kitna important hai. Bias ek extra number hai. Prediction model ka output hai. Loss error ka measure hai. Gradient batata hai ke loss ko kam karne ke liye weights ko kis direction mein change karna hai. Gradient Descent gradient ke opposite direction mein weights update karta hai. Learning Rate batata hai ke har step mein kitna bada change karna hai. Epoch ka matlab poora training data ek baar model ke through guzarna. Batch data ka chhota hissa. Iteration ek batch process karna.

---

# PART 10 — NEURAL NETWORK

Neural network insaan ke dimaag se inspired hai. Ek neuron ke paas inputs aate hain. Har input ka weight hota hai. Phir bias add hota hai. Phir activation function apply hota hai. Activation function decide karta hai ke neuron fire karega ya nahi. Input Layer data leta hai. Hidden Layers processing karte hain. Output Layer final prediction deta hai. Forward Propagation mein data input se output tak jata hai. Activation Functions mein ReLU, Sigmoid, Tanh, Softmax aate hain. Loss nikaalta hai. Phir Backpropagation aata hai. Backpropagation error ko output se input tak wapas bhejta hai aur har weight ko batata hai ke usne kitni galti ki. Phir Gradient Descent weights update karta hai. Ye human learning ki tarah hai, galti se seekhna.

LSTM RNN ka improved version hai jo lambi dependencies yaad rakhta hai. GRU LSTM ka simplified version hai. Transformer sabse modern architecture hai jo attention mechanism use karta hai. Har architecture ka apna problem, idea, working, example, aur limitation hai. Lekin sabka goal ek hi hai, data se patterns seekhna.

# PART 14 — TOKENS

Token text ka chhota hissa hai. Ye word se chhota bhi ho sakta hai aur bada bhi. Tokenization text ko tokens mein todne ka process hai. Har token ka Token ID hota hai. Vocabulary saare unique tokens ka set hai. Word linguistic unit hai, token computational unit hai. Subword tokens tab use hote hain jab word vocabulary mein nahi hota. Input tokens user deta hai. Output tokens model generate karta hai. Context Window maximum tokens ki limit hai. English example: I love AI. Roman Urdu example: Mujhe AI pasand hai.

# PART 15 — EMBEDDINGS

Embeddings text ko numbers ke vectors mein convert karte hain. Similar words ke vectors bhi similar hote hain. King aur Queen ke vectors paas hote hain. Man aur Woman ke vectors paas hote hain. King minus Man plus Woman equals Queen jaisa relationship bhi ban jata hai. Cosine Similarity do vectors ke beech angle measure karta hai.

---

# PART 16 — TRANSFORMERS

Transformer kyun aaya? Kyunki purane models slow thay aur lambi dependencies nahi samajh paate thay. Transformer ne Attention mechanism laya. Encoder input samajhta hai. Decoder output generate karta hai. Self-Attention mein har word doosre words se poochta hai ke tum mujhse kitne related ho. Query, Key, Value use hote hain. Attention Score nikaalta hai. Softmax apply hota hai. Weighted Information milti hai. Positional Information batati hai ke word kahan hai. Feed Forward Network har position par apply hota hai. Residual Connections information skip karne dete hain. Layer Normalization training stable karta hai.

---

# PART 17 — SELF-ATTENTION

Sentence hai: The cat sat on the mat because it was tired. Ab it kis word ko refer kar raha hai? Cat ya mat? Self-attention yeh samajhta hai. It ka Query cat ki Key se match karta hai. Isliye it ka attention cat par zyada jata hai. Tired bhi cat se related hai. Query, Key, Value se Attention Score banta hai. Phir Weighted Information milti hai. Phir Updated Representation banti hai.
